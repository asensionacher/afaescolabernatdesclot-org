# Assets de la Escuela

Esta carpeta es para los recursos gráficos de la escuela.

## Archivos necesarios:

### Logo
Coloca el logo de la escuela con el nombre:
- `logo.png` (Tamaño recomendado: 200x200px o superior, formato PNG con fondo transparente)

### Favicon
Coloca los siguientes archivos de favicon:
- `favicon.ico` (16x16 y 32x32px)
- `favicon.svg` (versión vectorial del favicon)
- `apple-touch-icon.png` (180x180px para dispositivos Apple)

### Manifest (Opcional)
- `manifest.json` - Para configurar la PWA (Progressive Web App)

## Instrucciones:

1. Añade el logo de la escuela como `logo.png` en esta carpeta
2. Puedes generar los favicons usando herramientas online como:
   - https://realfavicongenerator.net/
   - https://favicon.io/
3. Coloca todos los archivos generados directamente en la carpeta `public/`

Una vez añadidos, aparecerán automáticamente en la web.
