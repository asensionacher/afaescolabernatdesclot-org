# Documentos PDF del AFA

Este directorio contiene los documentos PDF descargables de la web.

## PDFs necesarios:

### 1. `descuentos-ampa.pdf`
- **Descripción**: Lista de descuentos y beneficios para socios del AFA
- **Contenido sugerido**:
  - Listado de comercios y servicios del barrio que ofrecen descuentos
  - Porcentaje o tipo de descuento ofrecido
  - Condiciones para acceder al descuento
  - Información de contacto de cada comercio
  - Logo del AFA y la escuela

### 2. `formulario-inscripcion.pdf`
- **Descripción**: Formulario de inscripción al AFA
- **Contenido sugerido**:
  - Datos del socio/a
  - Datos del estudiante
  - Autorización de imágenes
  - Información sobre la cuota anual
  - Domiciliación bancaria

## Cómo añadir los PDFs:

1. Crear los PDFs con el contenido correspondiente
2. Guardarlos en este directorio con los nombres exactos indicados arriba
3. Los enlaces en la web funcionarán automáticamente

## Enlaces en la web:

- **Descuentos**: Sección "Serveis" > "Descomptes per Socis"
- **Inscripción**: Sección "Contacte" > "Apunta't!"
